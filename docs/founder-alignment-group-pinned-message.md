# AiJia Context 群置顶说明

> 使用时机：每日一次 24 小时防漏复核部署并验证后，置顶到 Ivy 与 James 的唯一批准群。

📌 **AiJia Context｜群内使用与工作机制**

机器人会自动读取本群新增的文字和支持解析的文档，并完成五类工作：

- 从群聊和文件中动态识别项目；
- 判断信息是项目、原则、产物、研究还是想法；
- 区分 Ivy 和 James 的当前观点与历史观点；
- 判断“缺少表达”和“真实分歧”；
- 避免把沉默、旧意见或相似措辞误判成共识。

**它怎么工作**

消息到达后立即保存 → 同一话题安静约 5 分钟后批量分析 → 更新项目地图和双方理解。机器人默认保持安静，不说话不等于没有记录。每天还会复核最近 24 小时的飞书历史，补回没有通过实时事件到达的内容；重复内容不会重复分析。

**怎么确认是否处理、有没有遗漏**

查询结果会显示最后收到消息、最后完成分析、最后防漏复核、待处理任务、失败及不可读缺口。已送达 Bridge 的消息会持久化并重试；读取不到的文件或消息会显示为缺口，不会被当作已经覆盖。

直接在群里发送以下指令，无需 `@机器人`：

- `查看工作地图`
- `查看对齐：项目名`
- `查看待对齐`

当前验证阶段只响应手动查询，不会自动推送地图或分歧提醒。验证准确后，只有影响方向、下一步、负责人、期限或完成标准的分歧才会触发自动提醒。机器人只整理 Context，不自动执行任务；未回复不等于同意。
