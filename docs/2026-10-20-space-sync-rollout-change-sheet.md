## 一句话

首期只接 Smart Listing 一页的正文，暂不接评论：
- 你把页面存成 Markdown 发给我，我转成同步格式，先在生产副本上预览；
- 你看过预览后，在生产按「接收 → 分析 → 展示」三步依次打开开关；
- 每一步都能只靠关开关立即回滚；
- 页面原文和每一次更新的历史版本都长期保留。

自动同步、评论和更多页面，等这一页稳定后另走变更单。

## 上线步骤

### S0｜真实页面只读试点（不改生产）

1. **导出：** 你把 Smart Listing 页面存成 Markdown 发给我，并告诉我页面最后更新的大致时间。
2. **本地转换和校验：** 我用 C1 转换，只输出统计，不展示正文：
   - 段落数、总字数；
   - 格式校验是否通过；
   - 覆盖情况：正文完整，评论未同步。
3. **生产副本预览：** 在生产数据库的只读副本上，先登记映射、再导入、再跑一次 Space 分析，生成对比预览（Grove 一张图加文字卡）。

门禁：副本前后哈希一致；生产数据库、开关和镜像都不变；没有群消息。

- **S1–S3：** 把对应开关改回 false 并重启，Space 内容立即从所有视图消失，飞书侧功能不受影响。已导入的来源保留，不删除。

## 不做

- 不扫描整个 Space，只读登记过的页面。
- 不反向修改 Space 页面。
- 不让 Space 内容新建、改名或改阶段工作地图条目，只补充已登记的条目。
- 不把评论自动当成共识。
- 不发群消息，不执行 Todo，不接 API Key，不保存 ChatGPT 登录态。

## 风险

- **额度：** Codex 额度未恢复时，S0 第 3 步和 S2 都做不了；C1–C3 和 S1 不受影响。
- **手动同步会滞后：** 页面更新后要等你再发一次 Markdown，工作地图才会更新。Space 新鲜度会显示最后一次同步的时间，不会把旧内容当成最新。
- **Markdown 不带段落 ID：** 段落 ID 由内容生成，一段改了字就算成新段落。这对「本周/今日有变化」的判断没有影响，但没法追溯某一段的逐字改动历史，只能看整页的版本。
- **页面结构：** Space 页面由多人和多个 AI 局部编辑，没有固定结构，摘要质量要靠 S0 的预览来判断。
