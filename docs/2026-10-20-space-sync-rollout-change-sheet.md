## 一句话

首期只接 Smart Listing 一页的正文，暂不接评论：
- 你把页面存成 Markdown 发给我，我转成同步格式，先在生产副本上预览；

## 上线步骤

### S0｜真实页面只读试点（不改生产）

1. **导出：** 你把 Smart Listing 页面存成 Markdown 发给我，并告诉我页面最后更新的大致时间。
2. **本地转换和校验：** 我用 C1 转换，只输出统计，不展示正文：
   - 段落数、总字数；
   - 格式校验是否通过；
   - 覆盖情况：正文完整，评论未同步。
3. **生产副本预览：** 在生产数据库的只读副本上，先登记映射、再导入、再跑一次 Space 分析，生成对比预览（Grove 一张图加文字卡）。
   - Space 分析要用 Codex，**要等额度恢复**。
4. **你审阅：** 页面摘要、本周进展、下一步和卡点是否准确，每一条是否都能对上原文。

门禁：副本前后哈希一致；生产数据库、开关和镜像都不变；没有群消息。

### S1｜发版并开启接收（生产）

1. 按以往流程发版 C1–C2，门禁和回滚资产照旧。
2. **密钥：** 在服务器生成 HMAC 密钥文件 `/opt/feishu-codex/secrets/space-sync-hmac`，权限 600。值不显示，也不写进仓库或记录。
3. **开关：** 设置 `SPACE_SYNC_INGEST_ENABLED=true`，其余两个仍为 false，重启 Bridge。
4. **登记：** 用 `register-space-mapping --apply --change-ref <本变更单>` 只登记 Smart Listing 这一页。首期不登记作者。
5. **导入：** 用 `import-space-sync` 导入 S0 那份 envelope。

门禁：
- 接收入口只能从本机访问，nginx 没有转发它；
- 数据库完整；
- 只多出 1 个页面绑定和本次的来源记录；
- Space 分析任务只排队、不执行；
- 工作地图预览与发版前完全一致。

### S2｜开启分析（生产，影子阶段）

1. 等 Codex 额度恢复后，设置 `SPACE_SYNC_ANALYSIS_ENABLED=true`，重启 Bridge。
2. 排队的 Space 分析任务执行，生成页面摘要。

门禁：
- 分析成功、没有失败重试；
- 摘要的每一条都能在原文里逐字找到；
- 工作地图、项目进展和处理状态的输出与开启前完全一致。

### S3｜开启展示（生产）

1. 设置 `SPACE_SYNC_WORKMAP_ENABLED=true`，重启 Bridge。
2. 你发一次「查看工作地图」和「查看项目进展：Smart Listing」，作为唯一一次人工验收。

门禁：
- Smart Listing 卡片出现页面摘要、本周进展和 Space 新鲜度；
- 其他条目和编号不变；
- 没有自动群消息。

### S4｜之后另走变更单

- 接入 Family First 和「超级个体到超级团队」。
- 接入评论：先看有评论页面的实际样子，决定 bot 评论怎么归属；同时修好「只开分析时评论观点提前露出」的问题。
- 自动同步（T2）：手动发 Markdown 重复几次后，改由你本机的 Codex App 定时任务读取并提交。它依赖你的电脑在线，状态里要标成本机运行。
  - 要走网络提交，还需要另外决定是否在共享 nginx 上开放接收入口。

## 回滚

- **S1–S3：** 把对应开关改回 false 并重启，Space 内容立即从所有视图消失，飞书侧功能不受影响。已导入的来源保留，不删除。
- **发版：** 照旧保留回滚镜像、app 快照和停机时的数据库备份，任一门禁失败自动回滚。
- **登记或导入出错：** 用切换前的数据库备份恢复。这一步只在你同意后执行。

## 不做

- 不扫描整个 Space，只读登记过的页面。
- 不反向修改 Space 页面。
- 不让 Space 内容新建、改名或改阶段工作地图条目，只补充已登记的条目。
- 不把评论自动当成共识。
- 不发群消息，不执行 Todo，不接 API Key，不保存 ChatGPT 登录态。

## 风险

- **额度：** Codex 额度未恢复时，S0 第 3 步和 S2 都做不了；C1–C2 和 S1 不受影响。
- **手动同步会滞后：** 页面更新后要等你再发一次 Markdown，工作地图才会更新。Space 新鲜度会显示最后一次同步的时间，不会把旧内容当成最新。
- **Markdown 不带段落 ID：** 段落 ID 由内容生成，一段改了字就算成新段落。这对「本周/今日有变化」的判断没有影响，但没法追溯某一段的逐字改动历史，只能看整页的版本。
- **页面结构：** Space 页面由多人和多个 AI 局部编辑，没有固定结构，摘要质量要靠 S0 的预览来判断。
