Docker 自己报的 `RECLAIMABLE`（镜像 9.1G、缓存 11.7G）是另一种口径：镜像之间共享层，每个飞书镜像 1.53G 里有约 0.94G 是共享的，所以按单个镜像大小相加会重复算。

清理的 15.2G 里，飞书项目自己的发版产物（旧镜像、构建缓存、预览副本）约 10.7G；系统日志（`messages`、`secure`、`cron`、journal）约 4.6G，和飞书服务无关。

1. **预览目录**：11 个预览目录是一条命令全部删掉的。当时的依据是它们都是 `docker run --rm` 产出的只读生产库副本，已有的备份是单独存放的。事后核查：当前没有任何容器挂载 `preview/` 目录（0 个）。但我没有逐个确认里面没有预览期间新增的东西，也不能恢复。本机保留了各次预览下载回来的输出（图片、文本、digests.json），备份没有受影响。以后清预览目录前，逐个检查：没有容器挂载、没有未取回的输出、不是唯一副本。
